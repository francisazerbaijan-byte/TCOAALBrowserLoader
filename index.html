Using your own game files

  1. Have a complete, unmodified copy of your legitimately obtained game files available on your device.
  2. Open the browser importer and select the game folder or ZIP archive.
  3. Keep the browser's site data enabled if you want imported files and saves to persist.

Important setup notes

The loader still checks imported files for integrity and origin. This homepage does not disable license checks or include copyrighted game files.

GitHub Pages project sites live under a repository subpath. The existing browser loader includes root-relative URLs and service-worker paths, so those must be adapted for a fully functional project-site deployment. School-managed Chromebooks can also restrict storage or file access.
